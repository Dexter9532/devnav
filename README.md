# DevNav

Development is better when your environment is structured and you know where
to find your projects. When working on multiple projects, keeping everything
organized can become difficult.

DevNav is a simple, free, and open-source tool for organizing and navigating
development projects.

## Development status

DevNav is a vibe-coded CLI tool developed with AI assistance. The project is
still in early development.

## Install

Install DevNav directly from GitHub using Cargo:

```bash
cargo install --git https://github.com/Dexter9532/devnav.git
```

Make sure `~/.cargo/bin` is in your `PATH`. You can then run DevNav from any
directory:

```bash
devnav init
```
